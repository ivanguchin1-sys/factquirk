Privacy Policy

Last updated: November 1, 2026

This policy covers Fact Quirk Uploader, a private application that uploads videos to the Fact Quirk YouTube channel.

Who uses it

The application is used only by the owner of the Fact Quirk channel. It is not offered to the public and does not let anyone else sign in.

Data accessed

With the owner's permission, the application uses the YouTube Data API scope youtube.upload to upload the channel's own videos and set their title, description, tags and publish time. It does not read, collect or store data about viewers or any other Google user.

Storage

The OAuth token that authorizes uploads is stored only on the owner's computer. No data is sent to any server other than Google's YouTube API, and no data is sold or shared with third parties.

Google API Services

Fact Quirk Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube's own handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions.
